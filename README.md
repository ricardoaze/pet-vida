
# 🐾 Pet Vida

## Pet Shop e Clínica Veterinária

Seu melhor amigo merece o melhor cuidado!

O Pet Vida é um projeto de site desenvolvido para um pet shop e clínica veterinária, com apresentação de serviços e possibilidade de contato e solicitação de agendamento pelo WhatsApp.

## ✨ Funcionalidades

- Página inicial com apresentação da empresa.
- Seção de serviços.
- Seção sobre a Pet Vida.
- Formulário de agendamento.
- Integração com WhatsApp.
- Layout adaptável para dispositivos móveis.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📋 Serviços apresentados

- Banho e Tosa.
- Consultas veterinárias.
- Vacinação.

## 📱 Contato

Os clientes podem preencher o formulário de agendamento e enviar as informações diretamente pelo WhatsApp.

## 🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta `pet-vida`.
3. Abra o arquivo `index.html` no navegador.
